# 手账背景提炼

从一张手账内页图中提炼出干净、可复用的背景底图，用于后续重新排版照片和文字。

## 核心工作流

整体分为两步：**AI 去元素**（image_edit）+ **后处理**（脚本统一规格）。AI 负责“决定保留什么、去掉什么”的视觉判断，脚本负责确定性的规格与白边检测。

### Step 1 — 用 image_edit 提炼背景

调用 `image_edit`（参考图 = 用户上传的手账内页），核心是构造一个精确的“保留清单 + 去除清单”提示词。

**Prompt 结构（重要，务必按此组织）：**

1. **先看原图，理解元素**：先 Read 用户提供的图，识别其中的照片、文字、插画、线描、胶带、贴纸、装饰元素分别在哪里。
2. **去除清单（明确列出）**：
   - 所有照片内容（描述位置和内容，如“左侧卧室窗景照片”）
   - 所有文字内容（标签文字、标题、正文、页码，逐条列出原文）
   - 明确说明“去除后自然露出下面的做旧牛皮纸底色”
3. **保留清单（明确列出，这是核心）**：
   - 所有装饰线描（飞鸟、海浪、帆船、海岛、灯塔等）
   - 所有胶带/贴纸粘贴痕迹
   - 插画（视用户需求决定保留或去除，默认保留，除非用户要求去掉）
   - 干花、海玻璃、绿植、贝壳等装饰物
4. **背景基调**：做旧米黄色牛皮纸质感，画面四边到边铺满。
5. **去白边要求**：在 prompt 中写“画面四边就是纸张边缘，绝对不存在任何白色背景、白色边框、外围留白……不要把纸放在桌面或白色背景上，不展示书本、不展示环境——纯平面扫描件”。

**示例 Prompt（可直接套用）：**
> 将这张手账页进行编辑：完全去除所有文字内容（[逐条列文字]）和所有照片内容（[逐条列照片]）。去除后自然露出做旧米黄色牛皮纸底色。完整保留以下装饰元素不动：[逐条列线描/胶带/插画/装饰]。整体保持做旧米黄色牛皮纸底色，竖版，画面四边到边铺满。输出一张干净的手账页背景底图，[保留的装饰元素]，但没有任何文字、没有照片、无任何白边。

**关键经验（从实践中总结）：**
- 图片生成模型常会在四周残留 3~10px 白边或把纸张放在白背景上。**务必在 prompt 明确“纯平面、四边到边、不要白桌面/白背景”**。
- 用户经常迭代“某个元素要不要保留”（如“左上角的城市也要保留”“不要保留底部撕边便签”）。每次迭代都基于**原图 URL**（不是上一张背景图）重新调用 image_edit，用新的保留/去除清单。
- 保留/去除清单要具体到“哪个位置、什么内容”，不能只写“参考原图保持一致”。

### Step 2 — 后处理（统一规格 + 白边检测）

用 `scripts/process_background.py` 完成下载、白边检测、统一尺寸、写入 DPI：

```bash
python3 scripts/process_background.py "<图片URL>" "<输出路径>" --width 2185 --height 3130 --dpi 300
```

- 输出目录：原图所在目录下的 `背景/` 子目录（不存在则创建）。
- 输出命名：`<原图文件名>-背景.png`（例如 `花鸟岛-在岛上浪费一个下午-右页背景.png`）。
- 脚本会自动：下载 URL → 检测四边白边并报告 → 转 PNG 并缩放到目标尺寸 → 写入 DPI。
- 若脚本报告“⚠ 检测到白边”，说明模型残留了白边，**应返回 Step 1 重新生成**（强化去白边提示），而不是直接裁切——裁切会损失内容且改变比例。

## 规格约定（可印刷）

| 参数 | 值 |
|---|---|
| 像素 | 2185 × 3130 px（竖版） |
| DPI | 300 |
| 物理尺寸 | 18.5 × 26.5 cm |
| 格式 | PNG |

若用户指定其他规格，按用户要求覆盖。

## 交付

每次生成一张背景，必须用 `present_files` 单独交付一次。交付后简要说明保留了什么、去掉了什么。

## 迭代

用户常基于上一张背景继续微调（“XX 也要保留”“去掉 XX”）。处理方式：
1. 始终基于**原内页图**重新调用 image_edit（不是基于上一张背景叠加去元素，避免累积失真）。
2. 只改用户点名的保留/去除项，其余维持。
3. 重新走 Step 2 后处理并交付。
