# 素材库

每张照片卡的相框（画框）、照片、配套贴纸、胶带及卡内说明文字必须整体生成一张透明 PNG，合成后只占一个普通图像层，不拆成多个图层或多子层组。

每份分层 PSD 必须合入一个独立可见的主题 Logo，放在依据当前页面留白和对比确定的位置。缺失时使用 `/Users/hua/Documents/Skill/寻寻仔主题Logo生成/SKILL.md`，默认无文字、透明背景；现有合格同主题 Logo 可直接复用。任务图层以 `品牌Logo_` 命名并标记 `role=brand_logo`，准备与合成脚本都会拒绝遗漏 Logo 的任务。

共 5 张图像生成素材：1 张背景、2 张照片卡、2 张文字图像层。素材仅用于雨崩旅行手账页面重建，组件按原位与原比例复用。
