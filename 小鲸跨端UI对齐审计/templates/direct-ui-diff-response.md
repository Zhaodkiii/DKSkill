# 直接 UI 差距输出模板

用于用户说“对比 iOS UI，直接说明还有哪些差距，超级详细”。

```markdown
这版已经接近/还有明显差距。核心问题不是功能是否存在，而是：<一句话概括，例如“颜色职责、模块结构和状态表达还没有按 iOS 收敛”>。

**1. <模块名>**
- iOS 是：<参考端做法>。
- 鸿蒙现在是：<目标端现状>。
- 差距是：<具体问题>。
- 鸿蒙应改：<可执行建议>。

**2. <模块名>**
- iOS 是：...
- 鸿蒙现在是：...
- 差距是：...
- 鸿蒙应改：...

**颜色建议**
| UI 部位 | 鸿蒙建议色值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#F5F5FA` | iOS 淡冷灰。 |
| 主文字 | `#111111` | 标题和重要值。 |

**最该优先改**
1. <P0/P1 问题>
2. <P1/P2 问题>
3. <P2/P3 问题>

一句话总结：<直接结论>。
```

输出要求：

- 每条都必须说明 iOS 和鸿蒙各自是什么。
- 如果用户要求颜色，必须给色值表。
- 不要只输出抽象形容词。
- 不要把功能缺失写成视觉小问题。
