# iOS 到 HarmonyOS UI 色彩映射

这些色值用于截图审计和工单建议。实际落地时可按项目已有 token 命名替换，但视觉职责不要变。

## 基础色

| 用途 | HarmonyOS 建议色值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#F5F5FA` | iOS 淡冷灰页面背景。 |
| 卡片背景 | `#FFFFFF` | 主信息卡、表单卡、附件卡。 |
| 浅灰 cell 背景 | `#F2F2F7` | 药品行、列表 cell、输入容器。 |
| 分隔线 | `#E5E5EA` | 卡片内细分割线。 |
| 主文字 | `#111111` | 标题、重要数值、药名。 |
| 次级文字 | `#8E8E93` | label、副信息、计数。 |
| 三级说明 | `#9B9BA1` | 提示说明、占位辅助。 |
| placeholder | `#C7C7CC` | 输入框占位。 |
| 系统蓝 | `#0A84FF` | 返回、管理、选中 tab、链接。 |

## 紫色主视觉

| 用途 | HarmonyOS 建议色值 | 说明 |
| --- | --- | --- |
| 紫色图标渐变起点 | `#C13AF0` | 处方、计划、医院卡主图标高亮。 |
| 紫色图标渐变终点 | `#6B5CF6` | 处方、计划、医院卡主图标主色。 |
| 主紫按钮 | `#D12BE8` | 拍摄添加计划等主操作。 |
| 浅紫按钮背景 | `#F7E9FB` | 次操作按钮，例如手动添加。 |
| 浅紫按钮边框 | `#EBC3F5` | 次操作边框。 |
| 紫色文字 | `#C729E0` | 次操作文字、部分强调。 |
| 主卡淡紫边框 | `#F0C8F5` | 服药计划大卡片边框。 |

## 医疗蓝

| 用途 | HarmonyOS 建议色值 | 说明 |
| --- | --- | --- |
| 诊断卡背景 | `#EAF6FF` | 诊断模块小卡片。 |
| 诊断卡边框 | `#BFE1FF` | 诊断模块边界。 |
| 诊断图标/标题 | `#0A84FF` | 诊断标签、听诊器图标。 |
| 关联病例图标底 | `#E3F2FF` | 已关联病例入口图标块。 |

## 状态色

| 状态 | 背景色 | 文字色 | 使用说明 |
| --- | --- | --- | --- |
| 已结束/已完成 | `#DFF8E8` | `#34C759` | 药品级结束或完成状态。 |
| 生效中 | `#F7D8FB` | `#C729E0` | 计划级生效状态，贴近 iOS 粉紫。 |
| 正常 | `#DFF8E8` | `#34C759` | 检验/检查正常。 |
| 异常/警告 | `#FFE8CC` | `#FF9500` | 异常或需关注。 |
| 错误/必填 | `#FF3B30` | `#FF3B30` | 输入错误、必填红色。 |
| 禁用 | `#E5E5EA` | `#FFFFFF` | 禁用按钮。 |

## 避免色

- 不要用亮绿色 `#7CEA58` 作为主卡边框或次按钮大底色。
- 不要用蓝紫渐变作为 iOS 纯紫主按钮的替代，除非参考端本身就是渐变。
- 不要用浅桃色配绿色字表达“已结束”，容易误读成警告。
- 不要让绿色同时承担主边框、主按钮、完成状态三种职责。
