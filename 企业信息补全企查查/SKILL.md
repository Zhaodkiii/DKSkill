# 企业信息补全（企查查）

把目标工作簿（如供应链整合数据模型）「企业表」中缺企查查信息的企业，批量补全统一社会信用代码、法定代表人、注册资本、成立日期、注册地址、所属省市区、企业类型、纳税人识别号、注册号、组织机构代码、参保人数、营业期限、国标行业、英文名、企业规模、官网、电话、邮箱、企业简介、经营范围等字段。

## 输入与输出

- **输入**：目标工作簿 xlsx（含企业表）、企业清单（用户给或从企业表读缺信息的行）、企查查总表 xlsx（可选，`企查查高级搜索_合并总表.xlsx`，36 列）
- **输出**：在目标工作簿的企业表上填充/追加信息列（列 11-33），保存并交付本地文件
- **交付**：本地电脑编辑场景，交付本地文件路径，走 `present_files`；不导入飞书

## 前置必读

动手前先按 `sheet` 技能的 SKILL.md 与 refs 规范执行（表头定位、样式继承、交付门禁 `excel_formula_verify.py`）。本技能只定义"企查查信息补全"专属流程。

## 工作流

### Step 1 — 探查目标工作簿

- 打开目标 xlsx，定位「企业表」，确定**表头行**（本系列多为第 4 行）与数据行范围（表头行+1 到 max_row）。
- 读取现有列头：原始列（通常 A-K：统一企业ID / 企业全称 / 简称 / 供应链角色 / 国家地区 / 所属集团 / 状态 / 业务说明 / 原始企业ID / 来源编号）与企查查信息列（11-33，若已存在）。
- 记录样式基线：表头格字体/底色/对齐（常为 Arial 加粗 10、深蓝 FF1F4E78、居中）、数据格对齐（Arial 10、wrap_text）。新增/填充格继承此样式。
- 注意 B 列（企业全称）常存 `=HYPERLINK("#企业表'!A5","企业名")` 公式——读名称时用 `re.search(r'"([^"]*)"\)\s*$', v)` 解析出显示文本，**写回时不得破坏该公式**。

### Step 2 — 列出待补企业并判定来源

- 运行 `scripts/list_missing.py <目标xlsx> <企业表sheet> <表头行>` 列出缺信用代码（信息）的企业（ID + 全称 + 搜索关键词建议）。
- 加载总表 xlsx 建"企业名→36字段行"索引（`fill_company_info.py` 内置）。对每个企业，用 `master_keys()`（去备注括号、去"股份有限公司/有限公司"后缀、去"及"后缀）做**精确匹配**。
- **匹配到总表** → 该企业数据从总表取；**未匹配** → 进 Step 3 走企查查浏览器抓取。
- 常用总表文件：`/Users/hua/Documents/project/SupplyChain/汽车供应链/汽车产业链企业信息表/企查查高级搜索_合并总表.xlsx`（48,509 行，36 列）。

### Step 3 — 企查查浏览器抓取（未命中企业）

按 `references/qcc-scraping.md` 执行：搜索 → 选精确同名 firm 链接 → 详情页正则解析 → 逐家写入 `/tmp/qcc_results.jsonl`。要点：

- 用 `mac_computer_use_tool(plane="bu")` + `seed_browser_use`。
- 每次访问间隔 0.5 秒（搜索→详情、企业之间均 `time.sleep(0.5)`）。
- 登录/验证被挡 → 调用 `interaction_request_action(type="browserControl")` 请用户接管。
- **境外/品牌/多法人主体必须核对**：别盲抓第一个 firm，用同名候选判断正确法人（参考 qcc-scraping.md 的对照表）。分公司主体（"XX分公司"）不应作为主法人。
- 结果 JSON 的 `id` 字段必须等于目标工作簿统一企业ID，供 Step 4 关联。

### Step 4 — 写回工作簿

- 先**备份**：`cp 目标xlsx /tmp/改前快照.xlsx`（交付门禁 baseline 用）。
- 运行 `scripts/fill_company_info.py <目标xlsx> <企业表sheet> <表头行> <总表xlsx> <qcc_jsonl> --scope-ids <需处理ID列表,逗号分隔>`：
  - 对每个企业，优先总表精确匹配，否则取 qcc jsonl 对应 ID 的数据。
  - 只填充信息列 11-33，写入时继承表头/数据格样式，不破坏 B 列 HYPERLINK 公式、不覆盖原 A-K 列。
  - `--scope-ids` 传本轮新增/待补企业的统一企业ID，跳过已填行。
- 若总表来源缺省/市/区县或企查查来源缺省/市/区县，运行 `scripts/fill_region.py <目标xlsx> <企业表sheet> <表头行>` 从注册地址解析补全（境外主体解析为空，跳过）。

### Step 5 — 验证与交付

1. 抽查新增企业各信息列非空覆盖（信用代码、法人、注册资本、成立日期、注册地址、企业类型、注册号、参保人数、营业期限、国标行业、企业规模、邮箱、经营范围应接近 100%）。
2. 确认 B 列 HYPERLINK 公式未被破坏、A-K 原列未改动、所有 sheet 保留。
3. 跑交付门禁（带 baseline 与 scope，scope 写本轮改动范围如 `企业表!K110:AH141`）：

   ```bash
   python3 scripts/excel_formula_verify.py <目标xlsx> 60 --baseline /tmp/改前快照.xlsx --scope '<sheet>!<列><起始行>:<列><结束行>'
   ```

   退出码 3 是确定性错误修完重跑；退出码 4（LibreOffice 未装）是正常终态，交付说明注明"公式未重算，可在 Excel 刷新 Ctrl+Alt+F9"。
4. `verifier-hub` 结构校验 + 必要时 `artifact-preview` 渲染核对。
5. 用 `present_files` 交付本地文件路径。

## 脚本清单

| 脚本 | 作用 |
|---|---|
| `scripts/list_missing.py` | 列出缺企查查信息的企业（ID/全称/搜索关键词） |
| `scripts/fill_company_info.py` | 从总表+qcc jsonl 写回信息列，总表优先 |
| `scripts/fill_region.py` | 从注册地址解析补全省/市/区县 |
| `scripts/parse_region.py` | 单条/批量地址→省市区解析（被 fill_region 调用，也可独立用） |

抓取细则、字段解析正则、境外主体对照见 `references/qcc-scraping.md`。
