## 状态定义

| 状态 | 使用条件 |
| --- | --- |
| 已验证对齐 | 两端代码/测试证明相同契约和可观察行为已实现。 |
| 部分对齐 | 已有目标端实现，但字段、失败分支、权限、缓存、并发或验收仍有缺口。 |
| 待实现 | 参考端能力已确认，目标端没有对应实现或仅有空壳。 |
| 不适用 | 能力确实没有目标端业务需求或受平台限制不能提供；必须说明替代产品行为。 |

## 维护规则

1. 只引用真实服务端/客户端路径、可访问官方 URL 和已核验本地示例；后端字段和错误语义优先于任一客户端实现。
2. “已验证对齐”必须有测试、运行证据或逐字段代码对比；不能因接口名相同就标绿。
3. 每行只描述一个可验收功能；复杂能力拆为启动、认证、缓存、上传等多行。
4. 对新学习到且可跨项目复用的 HarmonyOS 对照，同步追加到 Skill 的知识库；仅项目特有内容只留在本矩阵。
