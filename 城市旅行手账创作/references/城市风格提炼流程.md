# 通用城市风格提炼流程

## 1. 哪些固定，哪些每次重新设计

| 固定执行标准 | 随城市、主题与真实素材改变 |
| --- | --- |
| 单页物理尺寸、两页载体关系、3/4/5寸相纸尺寸 | 照片数量、寸数组合、横竖方向、位置与角度 |
| 实拍来源完整，机械合成，人物与水印保留 | 选图角色、主图与次图的叙事关系 |
| 右页场景贯穿，仅文字局部底纸 | 场景内容、季节、天气、时间、远近景构成 |
| 自然拼贴、实体纸感、清楚阅读 | 皮面颜色、纸色、纹理、贴纸物件、绘画方式 |
| 记录与感受，事实可追溯 | 人物、事件、观察细节、感受、段落结构 |
| 每主题独立归档，完整PNG与打印PDF | 标题、主题数量、封面构图、字体风格、全套色彩 |

标准是执行和质量边界，不是固定城市模板。不能只换城市名与照片，其余沿用上一城；也不能固定所有城市都是深绿皮面、复古红邮戳、水彩洋房和咖啡。

## 2. 从真实素材提炼，而不是先套印象

每主题完成来源与全图检查后，在`制作记录.md`写清以下字段：

1. **记录核心**：是谁在何处经历了什么；本页要保存哪个片刻。没有用户亲历就明确作者摘记与编辑感受。
2. **实际环境**：照片中的季节、天气、时间、光线与活动节奏；是否混合多个时间，只说明真实可确认的范围。
3. **城市识别依据**：2–4项与本主题有关的建筑/地形/植被/街道/地方生活物件。逐项注明来自哪张照片或哪段正文；具体地标核外形，不能用网络刻板符号凑城市感。
4. **色彩提取**：由照片和故事选主色、辅助色、文字色与皮面色，记录依据。晴海、灰雨、夜景、雪地、红砖街区不能统一成一套暖绿棕色。
5. **材质与表现**：皮面手感、纸张冷暖、照片白边、胶带材质、插画方式和字体气质。皮面载体固定，皮色与材质视觉变化；插画可以水彩、版画、铅笔、纸艺、克制线描等，不默认全部复古邮票风。
6. **场景与布局**：远景、近景、文字净空、相纸组合与照片之间的背景留白。只要满足尺寸/可读/不遮挡，主图位置、照片横竖与重心自由确定，不固定左文右三格。
7. **独立贴纸**：从本页环境和事件选少量真实相关物件，说明各自如何衔接照片；没有叙事作用就不加。胶带、邮戳不是必须全用；不伪造凭证。
8. **本城差异**：写一句“这一城/这一主题与上一稿不同在哪里”，必须涉及实际环境与布局或材质，不能只说城市名变了。

素材不能支持某个符号、季节或事件时省略，不用生成模型补事实。

## 3. 风格方向示例（只作推导示例）

| 素材实际环境 | 可推导的视觉方向 | 不能自动添加 |
| --- | --- | --- |
| 海岛晴天、岩岸与渡船 | 海玻璃色与沙色、海面光线、船绳/票根形态、开阔留白 | 未出现的灯塔、虚构船班和票价 |
| 江南雨巷、河埠与湿石路 | 青灰与湿绿、低饱和柔光、瓦檐/窗格/雨滴、轻线描 | 任意著名古桥或他城园林 |
| 山城夜行、坡道与灯光 | 深蓝与暖灯、台阶/立体街巷、局部夜光与剪纸层次 | 虚构路线图、所有照片都强调成夜景 |
| 雪山或北方冬日 | 冷白与岩灰、蓝灰阴影、针叶/山线/脚印、清淡纸纹 | 照片没有的极光或雪峰 |
| 历史红砖街区、晴天散步 | 砖色与叶色、建筑窗框、树影和日常细节 | 固定上海梧桐、咖啡、深绿皮面 |
| 现代港口、城市海风 | 混凝土灰与海蓝、岸线/船体/栏杆、简洁线条 | 他城天际线或虚构航行经历 |

同一个城市可以因为主题和天气采用不同方向。例子不能当城市分类规则，也不要求先去查整城所有地标；使用已核验的本主题材料就能推导。

## 4. 生成提示词必须体现当前城市的设计依据

提示词写实际城市/主题、可确认环境、真实场景元素、主辅色与材质、照片预留关系、文字局部底纸和物理页结构。不能发送仅替换城市名的固定长提示词，也不能把未经填写的占位符送去生成。

生成层只负责插画、载体与装饰，照片与文字机械合成。右页景色全幅贯穿，禁止统一大色块托照片；两张竖页尺寸固定。场景不足先改场景，不能用更大照片或更多贴纸掩盖空背景。

## 5. 全套一致性和主题变化

同城全套共享少量视觉语言，例如统一皮面材质、正文文字色、照片工艺和字体体系。各主题的景色、主辅色、光线、照片组合与贴纸随记录变化；不把全套一致理解为相同构图、相同三张框或相同装饰。

初步完成后同时查看各主题预览：它们应能归为同一套，又能看出各自故事。再暂时遮住标题与照片检查场景，确认它仍有当前环境的特点；不能仅靠地名和照片识别。

## 6. 跨城市验收问题

- 去掉城市名后，背景是不是仍然上一城的建筑和物件？若是，重新设计。
- 主色、皮面和贴纸有没有可核验素材依据，而不是复制上一稿？
- 照片组合、画面重心与文字块是否因本次故事变化？
- 有无与照片天气、季节、时间冲突的背景？
- 具体地标是否准确，通用装饰是否被误标为真实地点或票据？
- 工艺标准与页面/照片尺度是否仍然统一？风格变化不能突破尺寸或水印要求。

这些问题逐主题记录结果；不能只在技能里写“每城不同”但实际仍套同一模板。
