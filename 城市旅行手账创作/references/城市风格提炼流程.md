# 城市风格提炼流程

适用阶段：仅在用户明确指定创作主题后使用。第一阶段先按主技能完成十个大主题规划、主题确认、素材采集与每个小主题至少三版详细内容，交付主目录文档后等待创作指令；本文不授权提前生成图片。
目录约定：城市主目录保留主题总表与目录说明；大主题进度文档放 `成品/`，小主题素材与三版文档放 `成品/<小主题>/`。源照片只在 `素材/` 权威归档，按noteId引用。已有及实际新增版本保存于对应小主题“V序号-内容简述”目录，不放历史；每版保存原始图、说明、来源和验收，每版每页一图，不自动生成派生副本。历史只保存旧稿与整理证据；详细结构以主SKILL第0节为准。


从已核验的本主题照片和文字提炼，不先套“某城必用某颜色或某物件”。参考作品只取设计方法：成都的纸张层次，舟山的具体情境，雨崩的文字节奏与活动物件。

在生成前写一份`成品画面说明.md`：

1. **这页讲什么**：地点、记录核心、用户是否有亲历、第一人称要表达的感受。作者独立经历不合成用户的一次旅行。
2. **环境依据**：来自照片或正文的地形/建筑/植被、天气、季节、光线和活动；不能凭刻板印象补地标。
3. **颜色和质感**：从照片提取主色、辅色、文字色、皮面色；说明纸张温度、撕边、压痕、胶带、装饰笔触与阴影。
4. **完整场景**：背景优先是一整幅跨越左右页的连贯场景，统一空间、远中近景、光线与色彩，从页边延续到照片间；依据每张照片的地点、季节和体验写出呼应关系。正文净空自然融入场景，照片周围降低细节与对比，承托女生主视觉；相纸边界仍可辨识。不能以零散贴纸或局部拼景替代完整背景。
5. **照片角色**：主图与次图的具体人/景内容、方向、相纸尺寸目标、视线、位置、禁遮区域，不能增添不存在的照片。
6. **手撕细节**：不同的裂口深浅、纤维、卷角、纸厚、局部阴影；胶带有撕断末端与皱纹。纸卡数量由文案需要决定，不把正文切成整齐一排卡片。
7. **节制**：只放与主题有关的小物、植物、地图线或笔记；日期、票根、路线和数据有证据才写。与上一主题不同之处必须来自本页的环境或叙事。

将以上写成**一条完整成品的图像生成提示词**，一次生成包含载体、场景、纸卡、贴纸、照片关系和文字的完整跨页。无需单独生成背景、撕纸、相框、花草再机械合成。生成后打开整图验收；失败时改完整提示词再生成整页。若用户转而要求原片像素保留或毫米级相纸，请改用可校准源照片的方法，并把方法变更告诉用户。

九扣固定规格：中央九个完整闭合扣环，3＋3＋3分组，相邻中心距为19、19、50.8、19、19、50.8、19、19 mm，首末扣中心跨度215.6 mm；组间大间距约为组内2.67倍。生成说明与提示词必须写入此规格，验收九扣全部可数、分组正确、无遮挡；不接受六扣或九扣等距。毫米数值是画面设计规格，不把整页生成的视觉验收称为加工精度验证。
