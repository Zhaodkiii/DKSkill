# 制版记录与检查

每主题一个`制版记录.json`，与最终PNG/PDF同目录。路径优先主题内相对路径，外部权威归档可用绝对路径；不能引用即将消失的临时文件。

## 尺寸检查脚本所需字段

| 字段 | 内容 |
| --- | --- |
| `dpi` | 300 |
| `pagePhysicalCm` | `[18.5,26.5]`，宽高顺序 |
| `singlePagePx` | `[2185,3130]` |
| `fullWithCarrierPx` | 整张PNG真实宽高，载体另计 |
| `leftPageBox` / `rightPageBox` | `[x1,y1,x2,y2]`半开矩形，每张宽2185、高3130 |
| `finalPng` / `printPdf` | 主题目录内的真实文件名 |
| `photos[].file` | 实拍源文件路径 |
| `photos[].sha256` | 实际源文件SHA-256，不填示例hash |
| `photos[].inch` | 整数3、4或5 |
| `photos[].paperOuterSizePx` | 相纸旋转前外框，含白边；只允许尺寸表内值或其横向交换 |

完整复现还需：各层持久路径、生成层原生分辨率、照片作者/noteId/角色、内图区、源裁切框、缩放方式、旋转中心/角度、最终位置、有效照片掩码、文字字体与字号/行距/边界、图注位置、禁覆区。这些由实际合成程序记录；尺寸脚本不能验证它们。

## 运行

使用已有Python与Pillow，无需安装框架：

```bash
python3 /Users/hua/Documents/Skill/城市旅行手账创作/scripts/check_print_spec.py --self-test
python3 /Users/hua/Documents/Skill/城市旅行手账创作/scripts/check_print_spec.py '/绝对路径/主题/制版记录.json'
```

脚本检查尺寸、相纸外框、源hash、图片解码、PNG的DPI、PDF两页MediaBox。默认导出为已有Pillow生成的简单两页PDF，MediaBox可直接检查；其他PDF结构如果无法直接解析则明确失败，使用已经安装的PDF工具读取MediaBox并记录结果，不新增解析器、不声称自动通过。

有效照片像素核验在合成脚本中实现：从源照片按记录重新构造图块与变换，掩码只包含真实照片内图；逐像素与最终PNG对应位置比较。相纸和装饰不能加入掩码以掩盖照片错误。旋转插值的容差须说明；同样的处理链应尽量获得一致像素。检查残影、重复图注、错误天气、城市身份、人物和水印仍需打开成品人工核验。

`验收.md`逐项写“已通过/未完成/不适用”、证据和实际运行结果。技能自测通过只说明检查器的基础逻辑，不证明任何历史作品全部合格。
