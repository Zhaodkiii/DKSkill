## 2. 一套作品如何成立

全套一张封面、2–4个真实叙事主题（用户指定优先）。每主题一个文件夹，含完整双页、打印PDF、记录与感受、来源、最终照片、制版与验收。只创建实际主题；封面已合格则复用，不因修订内页重做封面。

记录部分有作者和具体事件；感受部分有可观察的画面细节。正文可采用“记下的片刻 → 照片里的细节 → 留下的感受”，但各主题不机械套相同小标题。攻略只在明确要求时采用。不同作者、不同日期和地点的素材是主题整理，不合成虚构的同一天。

左右页有阅读与照片的重点分工，但不能每主题都固定同一模板。照片允许出现在两页，只要正文、安全区与活页环不冲突。两张3寸、一张4寸等组合自由选择；两图能讲清楚时不补无关第三张。

## 3. 物理尺寸与照片尺寸

单页宽18.5cm、高26.5cm；300dpi像素2185×3130。内容跨页4370×3130。外围皮面另计，推荐整图4920×3530，中央150px、外围200px。载体不是第三张内容页，不把含皮面整图缩放到18.5×26.5cm。

3寸：600×900px（5.08×7.62cm）；4寸：900×1200px（7.62×10.16cm）；5寸：1050×1500px（8.89×12.7cm）。横向交换宽高。此寸数为本技能固定口径，不把不同门店的命名自动混用；用户另给冲印规格时明确记录替代值。

**整个相纸都在该尺寸内：照片、白边、撕边、内部图注都不能额外扩张相纸。** 外部图注和胶带是独立装饰层。旋转前相纸尺寸固定，旋转后的外接矩形变大是几何结果，不意味着照片换了寸数。

例如5寸相纸1050×1500，白边每边24px，则最大内图1002×1452；不同源图用contain完整适配并居中，剩余空间作为白边。若需要底部内置图注，可再缩内图高度，仍不加大相纸外框。用户说“照片自由组合”不是允许拉伸人物，或给所有相纸任意缩放。

打印PDF裁出两张内容页，各自约524.4×751.2pt；1px换算误差允许。检查真实MediaBox，打印100%实际尺寸。PNG应保存300dpi元数据，但元数据不替代像素/页面尺寸检查。

## 4. 背景和贴纸的边界

左页可有连续正文底纸；右页必须为完整城市/故事场景。右页照片之间应该能看到树枝、墙面、街道、海面或与本主题有关的环境，不能用通用牛皮纸遮掉。只有文字可有局部纸底，面积由实际字体边界与适量内边距决定。

照片本身是一张独立相纸贴纸；不用统一纯色大纸板托住整组照片。边缘可轻微撕边、略微倾斜、带透明胶带和薄接触阴影。主图与副图形成不等重心；间距不齐、方向不同，但视觉顺序明确，不故意凌乱。

装饰来自真实主题：树影页可用梧桐压叶与窗框线描，咖啡页可用杯碟与街角纸条；海岛则改成海面、绳结、贝壳，不能照搬咖啡。只生成装饰插画，地标核外形；装饰邮戳不是实际行程凭证。

相纸、胶带、叶片可互相压纸边；不可压脸、身体动作、建筑名牌、水印、正文或作者。透明资产先查Alpha极值和边缘，棋盘格背景不是真透明。皮面用连续皮纹，不重复平铺短条；中央黄铜环与纸张结构要合理。

## 5. 正确的合成策略

先有内容与实拍，再锁尺寸与关系，再制作干净场景层和独立贴纸，最后用本地图像工具机械合成实拍与文字。最终源素材、纸面、胶带、图注、有效照片掩码都应可追溯。

不要让模型修改已经包含实拍的完整稿。上海修订中曾尝试让模型仅改背景，然后覆盖源照片；模型改变了位置和大小，覆盖后留下双重相纸、重复图注与局部第二张照片。解决方式是重新取得干净街景层，按已登记尺寸重新合成，不继续在残影上补纸遮挡。

内部场景层属于生产素材，不另作为无照片成品或无字成品。用户只需完整稿。保存内部必要层是为了复现，不增加额外交付版本；合成脚本最后必须引用持久目录，不依赖临时路径。

## 6. 上海复盘中必须加强的精度项

最后效果达到“完整街景＋自然贴纸＋局部文字纸面”的方向，但不能把效果认可等同于全部物理与像素检查已经通过：

- 旧合成脚本的固定尺寸定义在**图像区**，随后又加60px宽、140px高纸框。这会把相纸外框做大。本版要求外框固定，白边和图注向内，尺寸检查直接核外框。
- 旧记录检查源hash和左页裁切，不能证明右页旋转后照片没有被装饰覆盖。本版要求有效照片掩码上的最终像素对比，再人工核水印。
- 旧完成脚本依赖`/tmp`草稿/前景。本版要求持久素材路径，关闭会话后也能重建。
- 300dpi输出来自既有素材缩放，不能宣称生成背景具有同等原生细节。记录每层实际分辨率。
- 初版打印PDF生成后未检查实际MediaBox。本版把PDF物理页尺寸加入验收。

这些是执行时需要真实完成的加强项，不把规则文档当成已经修好了历史成品。用户本次要求更新技能，不自动覆盖上海成品。

## 7. 逐主题验收表

| 项目 | 通过依据 | 不通过的返回阶段 |
| --- | --- | --- |
| 来源 | 10篇有效名单；完整归档；8张候选；选图与故事有具体贡献 | 采集/复用 |
| 内容 | 记录、作者归属、感受清楚；无冒充亲历或攻略填版 | 文案 |
| 页面 | 两张2185×3130；载体另计；单页净空与中央安全区正确 | 制版 |
| 相纸 | 每张外框符合3/4/5寸；白边不外扩；旋转尺度不变 | 照片合成 |
| 实拍 | 源hash＋登记变换＋有效照片像素对照；水印人工可见 | 照片合成 |
| 右页 | 全幅主题景色；只有文字有局部底纸；无大纯色照片底板 | 场景 |
| 拼贴 | 有主题关系、角度和层次；无固定网格、残影和重复图注 | 布局/合成 |
| 字体 | 全部实际汉字可显示；实际边界在纸底内；缩略/放大都检查 | 排字 |
| 打印 | PDF两页MediaBox、100%尺寸正确；页尺寸与源PNG裁切一致 | 导出 |
| 交付 | 每主题独立；完整PNG/PDF/正文/来源；持久可复现路径；没有附加空稿 | 归档 |

视觉项目必须逐主题实际打开；尺寸脚本不能代替视觉。未做的检查明确标未验收。
