# 城市旅行手账创作

**当前默认分两阶段：主题确认 → 素材采集 → 每个小主题至少三版详细内容与文档交付；等待用户明确指定创作主题后，再进入整页设计说明 → 一次生成完整跨页 → 打开验收。** 第一阶段不调用图片生成、不生成封面或手账成品，不因文档完成自动开始创作。以下完整跨页方法只适用于第二阶段。 一个主题的一次生成请求要描述最终画面中的全部关系，不先生成背景、相框、纸卡、胶带、花枝等零件，也不用脚本将这些零件层层拼回去。成品是完整有字、有照片视觉内容、有载体的原始输出图，每页只交付一个原始版。用户明确要透明素材、分层、像素级保留照片或可编辑版时，再按其要求改变方法；不要暗中把整页生成宣称为原片机械嵌入。

用户在本轮武功山修订中明确的要求：单页**宽18.5×高26.5cm**，照片外框3寸**6.0×8.9cm**、4寸**7.6×10.2cm**、5寸**8.9×12.7cm**；第一人称；纸卡与贴纸有真实手撕边；图片交付以本技能“只交付一个原始版”的最新规则为准，保留工具实际格式。这些口径取代旧文档中的5.08×7.62、7.62×10.16、8.89×12.7cm默认值与强制PDF流程。

## 0. 两阶段执行与文档交付（优先执行）

### 第一阶段 A：先确认城市与主题

先确定城市主目录：用户指定路径优先，工作区已是该城市目录时直接复用，不再嵌套同名城市目录。读取现有主题、素材与用户偏好，保留已有确认结果。

以整座城市为共同背景，规划 **10 个有区别的城市旅行大主题**。主题依据城市特色、热门景点、旅行目的地、拍照打卡、吃喝玩乐展开；女生照片是素材视觉优先级，不把十个主题都变成同一种人像机位合集。

下列只是覆盖方向，须按实际城市组织成十个具体主题，不机械套用或虚构不存在的体验：城市地标与经典初访、历史街区与人文、城市漫步与街拍、自然山水与公园、地方美食与市场、咖啡茶馆与甜品、文化艺术与展馆、夜景夜市与夜生活、游乐休闲与特色活动、近郊目的地与短途旅行。相邻主题需有明确边界；“热门”“小众”等判断注明依据，开放状态、营业信息与动态数据核对当前来源。

每个大主题下拆解若干适合的小主题，默认建议3–5个，按实际内容调整。**小主题必须落到可查证的具体对象**：景点名称、街区与路段、目的地、餐厅或门店及分店、市场、展馆、拍照位置、实际活动。不能只写“吃美食”“拍美照”“感受城市”等空标题。近郊地点注明所属地区及与本城的关系，不冒充市内景点；地点未核实则标“待核实”，不当成已确认项。

在城市主目录建立 `确认主题.md`，先完整写出可审阅方案，再请用户确认或修改：

- 城市、城市主目录、整体旅行定位、用户偏好、更新日期；
- T01–T10 十个大主题的名称、核心体验、代表性城市特色、与其他主题的区别；
- 每个小主题的稳定编号（如 T01-S01）、标题、具体地点或门店、可以吃/喝/玩/拍什么、纳入理由、预期素材类型、核实来源与待确认问题；
- 各主题状态：待确认／已确认／待调整；用户实际确认内容与时间，不自行代替用户确认；
- 后续素材文档链接与制作状态，初始一律为“未授权创作”。

主题方案核实只做必要查询，不在确认前批量下载素材或写完整成品内容。小红书查询只用 IAB。**用户确认主题后才进入第一阶段 B**；已明确确认的主题不重复询问，用户只确认一部分时只推进该部分，未确认的保留在文档中。

### 第一阶段 B：按已确认主题搜集对应素材

素材采集改为 **每个已确认小主题下的具体地方收集3篇不同 noteId 的有效图文笔记**。地方指实际景点、目的地、街区或餐饮门店；同一小主题包含多个地方时分别计数，不按大主题合并凑数。十个城市大主题的规划数量不变，不再设置每大主题十篇或全城100篇配额。同篇确实支持多个地方时可原位引用并标明贡献，全城独立笔记数按 noteId 去重统计。

执行第2节的 IAB 限制、女生照片主次与下载技能交接。每个地方的3篇笔记都须对应已读取的正文与已下载照片，至少2篇以女生旅行照片为主，另外1篇可补充城市特色、餐饮细节或正文依据。三篇仍不足以支撑内容或选图时，记录缺口与待补项，不虚构完成；不要默认扩展回十篇。不能用其他地点的人像为小主题充数。已有合格归档核验后复用，不重复下载。

每个大主题在 `成品/` 共同父目录建立一份 `T01-<大主题名>-素材与内容.md`，只维护小主题入口、数量与进度；每个实际推进的小主题在 `成品/T01-S01-<小主题名>/` 内建立同名的 `T01-S01-<小主题名>-素材与内容.md`，保存素材台账与详细三版内容。新素材存入 `素材/T01-<大主题名>/T01-S01-<小主题名>/`。先检查 `素材/素材索引.md`，已有noteId原位引用，不复制到新主题；旧归档目录允许保留并登记真实路径。向下载技能传入已授权完整链接、准确保存目录、IAB约束与已有索引。

素材文档记录：

- 大主题编号与确认状态、小主题列表、采集日期与完成状态；
- 每篇笔记的标题、作者、noteId、完整详情链接（保留访问参数）、发布日期（可见时）、读取日期、正文摘要、支持的小主题与事实；
- 图片实际路径、所属笔记、可确认地点、女生主体／城市辅助角色、候选用途与淘汰原因；
- 原始记录、来源台账、下载完整性报告的实际路径；逐篇图片数、完整性、失败与待补项；
- 小主题与“来源笔记—图片—事实”对应表；同一照片复用与多作者素材分别标明。

按下载技能完成全部正文图片下载与完整性核验后，才能据此确认内容。素材不足的小主题标记“待补素材”，继续补齐，不能用虚构内容填满三版。

### 第一阶段 C：依据素材，为每个小主题写至少三版详细内容

在对应的 `成品/T01-S01-<小主题名>/T01-S01-<小主题名>-素材与内容.md` 内，为 **每一个小主题** 写出 A／B／C 至少三个完整备选版本。三版是可供后续选用的内容稿，不是三个标题、三句摘要或三个图片提示词；不得只替换形容词。依据素材选择不同组织方式，例如：

- A 体验与叙事版：围绕具体场景、人物与可证实细节组织内容；无亲历记录时用观看感受或旅行愿望，不伪造已经发生的行程。
- B 路线与实用版：围绕怎么玩、吃什么、怎样串联地点与注意事项；只有单个目的地时写到访顺序和体验重点，不硬编跨地点路线。
- C 拍照与生活方式版：围绕女生与地点同框、已观察到的构图、街景、餐饮或休闲体验，具体建议与来源事实分别标明。

每版必须包含：

1. 独立标题、内容角度、适合的阅读或旅行场景；
2. 具体地点／门店／体验对象及已确认事实；
3. 详细正文，通常300–500字并分段；素材不支持时继续补充或标未完成，不能为字数编造亲历、对话、口味、天气和事件；
4. 3–5条具体看点或吃喝玩拍信息；有依据才写地址、路线、价格、营业时间，动态信息带核实日期与来源；
5. 建议配图的真实文件路径、对应人物与场景、2–4条图注草案；
6. 本版引用的笔记／其他核实来源、已知限制、待核实项及与另外两版的实质差异。

第一阶段的长内容用于选题与审阅，第二阶段再压缩成适合画面的短文案，不能套用后文“短文字清单”要求删掉详细三版。三版共有事实可在小主题事实表集中记录，但每版正文必须完整。

完成后更新 `确认主题.md` 中每个小主题的素材覆盖、三版内容链接与完成状态。交付前检查：十个大主题已列明；用户确认状态真实；推进范围内每个小主题有具体对象、可追溯素材及至少三版完整内容；未完成项明示。部分确认或素材受阻时只报告实际完成范围。

```text
  确认主题.md
  素材/
    素材索引.md                      # 按noteId登记唯一权威归档与当前采用报告
    T01-<大主题名>/
      T01-S01-<小主题名>/
        来源.md
        原始记录/
          <noteId>.json
          <noteId>-浏览器下载.json
          历史报告/                 # 旧失败、旧路径、被取代报告原件
        <noteId>-01.webp             # 实际格式和全部正文位置保留
        <noteId>-下载报告.json        # 当前采用报告；重试可带时间，由索引指明
    公共素材/<已有合集或地点场景>/     # 旧素材、跨主题共用素材的权威位置
  成品/
    T01-<大主题名>-素材与内容.md       # 大主题索引与进度，仅一份
    T01-S01-<小主题名>/
      T01-S01-<小主题名>-素材与内容.md # 对应素材与A/B/C详细正文
      <小主题名>-原始版.<实际格式>     # 每个实际页面仅一张当前原始图
      成品画面说明.md
      来源.md
      验收.md
      V1-内容简述/                  # 本主题原始图、说明、来源及验收
      V2-内容简述/                  # 有实际修订时保留，不预建空版本
  历史/
    旧稿/                           # 旧初稿、修订版、旧脚本、PDF
    整理记录/<整理日期>/              # 路径映射、原件、核验结果
```

- 城市主目录不再嵌套同名城市，不在根目录新增零散照片文件夹、`照片/`、新`初稿/`或新`修订版/`；不为未来十主题预建空目录。旧结构先核验并纳入索引；只有用户授权整理时迁移。
- `确认主题.md` 是授权与状态总入口，开头、总览和小主题进度必须同步为当前状态。历史状态明确标成历史；日志不能替代更新总表。分别记录“数量满足”“小主题素材覆盖”“三版完成”“用户授权”“成品状态”，数量足够不能自动代表整个主题完成。
- 大主题文档只汇总，小主题文档保存完整长内容，避免同一正文两处维护。城市根目录只保留主题总表与目录说明；大主题总览在 `成品/`，小主题三版文档与对应图片同目录，并由总表链接直达。小主题正文只维护一份，不复制到每个版本内。
- `素材/素材索引.md` 按noteId登记标题、权威目录、当前采用报告、正文位置数与完整性；同篇只保留一处权威照片归档。其他主题、成品来源及历史稿引用该处，不复制照片或整套台账。公共素材暂不归入某主题时不强行认定确认状态。
- 下载交接必须给出完整的最终保存目录；下载技能直接保存到该目录，不再自动添加一层合集／主题。保留noteId作为文件名标识，不以noteId、随机数字、日期给中文主题目录命名；已指定的T01-S01编号是主题编号，不是笔记ID。
- 同篇不同正文序号即便内容相同仍保留位置，不以内容去重破坏页面总数。跨目录同noteId、同序号、同字节副本才可在授权整理时合并；不同内容与未完成记录不能误删。联系表等检视辅助图单独注明用途，不计正文照片数。
- `成品/<小主题>/` 同时保留素材与内容文档、当前采用入口及该主题的全部已有版本。版本目录统一为 `V<序号>-<内容简述>/`，例如 `V1-日间江景/`、`V2-蓝调夜景/`；内容简述只写该版核心内容或变化，通常4–8个汉字，不加长句。直接在目录名体现区别，无需另建说明文件。版本放这些对应目录，不移入 `历史/`；版本内保留该版的原始输出、画面说明、来源与验收，未知或缺失记录如实注明。实际修订时使用下一版本号，不覆盖旧版、不预建空版本。当前采用版本单独登记，未经用户选定不能以最大版本号自动替换；可用文档链接或符号链接指向对应原始图，避免复制。每版每页一张原始输出，不为同版额外制作放大／打印／拆页副本，已有派生文件原位保留并标明用途。
- 历史稿有旧尺寸、旧流程或旧视觉验收时如实保留，不据此宣称符合新增九扣等要求。目录整理不生成新图、不修改原生像素或DPI、不新增创作授权。
- 本地文档使用可解析的相对链接或真实绝对路径；报告的 `source` 与 `files[].file` 必须指向当前存在的文件。原始提取JSON、浏览器实际下载临时路径、报告原件属于证据，保留原值；历史临时Downloads不存在不等于归档丢失。
- 迁移先留逐文件旧／新路径与哈希、文档和报告原件。更新所有可维护文档链接；对新位置的图片核验哈希、解码和序号数量，生成新采用报告并更新索引，不能直接改历史报告路径后冒称重新下载。纯本地整理不必重访网页，但须明确未更新网页事实与时效。结束检查文档链接、当前报告路径、图片哈希、原始图唯一入口及状态一致性。

**第一阶段最终交付是城市主目录中的 `确认主题.md`、`成品/` 内的大主题进度文档与各小主题目录内的素材及三版内容文档，素材索引记录真实归档。到此停止，等待用户明确指定要制作的大主题或小主题。** 不能把“主题确认”“继续搜集”“内容可以”理解成开始生成图片；不自动生成十套手账。

### 第二阶段：用户明确指定主题后才创作

“开始制作T03”“把T02-S01做成手账”等明确指令才启动本阶段。记录用户指定的主题及版本；用户只指定主题而没有选 A／B／C 时，根据素材完整度与画面适配选推荐版，记入文档，无需为普通选版重复确认。主题名称不唯一时先厘清对应编号。

只处理指定范围，读取相应素材与三版内容，确认缺失项后进入下文第1–5节的视觉设计、短文案整理、整页生成与验收。以一个具体小主题作为默认单页叙事单位；用户指定整个大主题时，根据其实际小主题组织页面，先写清页面分配，不把全部地点拥挤塞入一张跨页。尺寸和图片方法沿用后文规定。

## 1. 从现有项目与参考里提炼视觉语言

先审计指定项目、旧稿和素材，再创作。检查用户提供的参考成品，打开完整图像，而不是仅看文件名或贴图组件。成都、舟山、雨崩是可选参考，提炼其**方法**，不搬运地点、日期、数据和整张构图：

- 成都：毛笔大标题、粗糙纤维纸、撕边层叠、纸厚和接触阴影；真实场景物件与局部插画相互穿插。
- 舟山：景色进入正文页，文字直接写在有净空的纸上；叙事有呼吸感，不把每句都装进一个小便笺。
- 雨崩：短而有力的大标题、段落疏密变化、照片旁的一句话、与徒步有关的小物或线描。
- 本轮武功山V2教训：统一长方纸条、均匀排字、几何草叶和仅靠旋转照片，仍显得像排版稿。手撕效果必须由整页场景中的材质、边缘、压层、阴影与故事共同构成。

从本主题已确认的照片与文字写出：地点识别、季节/天气、远中近景、光线、主辅色、皮面与纸张、字体性格、实体小物、照片角色、留白、左右页阅读顺序。具体山峰/建筑外形有证据才写，不能凭城市印象加未出现的地标。参考作品的视觉只用于理解层次和节奏。

### 正式创作背景：完整场景承托照片

**背景必须完整，优先设计成贯穿左右页的一整幅连贯场景，与已选照片和当前小主题呼应，承托女生照片主视觉。** 这是第二阶段的画面要求，不提前触发图片创作。

- **一幅完整画面**：统一场景空间、透视、光线、主辅色与远中近景。场景从页边延续到照片之间，并在左右页保持视觉联系；中缝、金属环与纸张仍符合活页本结构。不能只有右页几块景色、角落装饰或每张照片背后各自一块背景。
- **从照片提取环境**：根据已选照片确定具体地点、季节、天气、时间、色彩与体验，写明背景如何回应照片。例如街巷照片由连贯街景承托，海边照片由天空、海面与岸线承托，咖啡或餐饮照片可由窗边、店内空间与桌面构成完整场景；不必每页都是城市远景。
- **完整但有留白**：背景覆盖整体构图，不等于处处塞满细节。正文区通过天空、雾、浅墙面、水面或简化的室内平面自然形成低对比净空；留白属于同一场景，不能用大块不相关纸板把背景截断。
- **照片优先**：照片的尺寸、清晰度与局部对比优先于背景。背景在照片四周适度降低细节密度、饱和度或对比，用道路、岸线、窗框等视线引导呼应人物；保留相纸边界与接触阴影，既融入环境又能分辨照片。不遮挡人脸、动作、水印和图注，不把女生照片缩小来迁就背景。
- **主题真实一致**：背景可用水彩、纸艺或其他统一插画方式表现，但不把多处互不相邻的真实地标伪装成同一实景，不把不同作者照片拼成同一次旅行。不生成假游客或虚构地标补空；照片季节、天气明显冲突时先调整选图或明确区分，不能硬接成同一时刻。
- **写入说明并验收**：`成品画面说明.md` 必须交代完整场景是什么、如何跨页延续、与每张照片的呼应点、正文净空和照片主次。验收时暂时忽略照片与贴纸，背景仍应读成一幅完整场景；看回整页时，女生照片仍是主视觉，背景与照片共同表达同一主题。零碎拼景、主题无关或背景抢主视觉均须修改完整说明后重做。

## 2. 真实内容、来源与第一人称

有现成照片、来源台账时优先复用，逐张打开确认主体、动作、环境、水印、作者与场景。第一阶段确认主题后，按第0节采集：每个已确认小主题下的具体地方3篇不同有效图文笔记，正文图片完整下载或核验已有归档；全部图初筛，至少8张独立候选，最终选2–4张。小红书搜索、详情读取与页面访问只用Codex内置IAB；下载前阅读 [小红书链接图片下载](/Users/hua/Documents/Skill/小红书链接图片下载/SKILL.md)，遵循其归档与核验流程。不因修订一个已具备素材的主题重新采集。

### 小红书素材主次：女生照片为主，城市特色为辅

此规则适用于新采集笔记、已有素材复用和最终选图。**女生是照片的主要视觉主体，城市景点、建筑、街巷或自然环境承担地点识别与旅行氛围的辅助作用。** 不能把以纯风景为主的素材集合写成符合要求。

- **搜索**：每个已确认小主题下的具体地方收集3篇不同有效图文笔记，必须在 Codex 内置浏览器 IAB 搜索。每条搜索词都必须原样包含“女生照片”，并带上城市及具体小主题／地点，例如 `<城市> <具体地点或小主题> 女生照片`；可再补充“旅行、拍照、人像、同框、写真、机位”等词。搜索结果不足时保留“女生照片”，改用更宽的地点或品类词扩展，不省略该词。禁止启动、连接或使用电脑上的 Chrome、Safari、Edge 等外部浏览器及其登录状态；IAB 受阻时保留进度并报告，不切换外部浏览器。
- **笔记筛选**：每个地方的3篇笔记中至少2篇以女生旅行照片为主要图片内容，最多1篇补充城市特色、细节或正文依据。只有小头像、远处无法辨认的人群，或仅一张女生照片其余全是风景的笔记，不计入女生照片主导笔记；依据作者自述及明确素材描述筛选，不凭外貌推断性别身份。
- **下载**：按具体地方登记3篇笔记的完整详情链接，再调用 [小红书链接图片下载](/Users/hua/Documents/Skill/小红书链接图片下载/SKILL.md) 下载每篇全部正文图片，不因主次筛选漏下载。下载完整核验后再筛图；保留原始照片与来源记录。
- **候选图**：至少8张独立合格候选中，女生主体照片至少6张；城市全景、建筑或现场细节最多2张。女生照片应有清晰人物、衣着或动作与真实旅行环境，不用无关室内写真凑数。
- **最终选图**：选2张时均为女生主体照片；选3张时至少2张；选4张时至少3张。主视觉必须是女生照片，具有更大的展示面积或更突出的画面位置；辅助城市照片不能抢占主体。优先用女生与城市特色同框的照片，同时满足人物与地点表达。
- **制作与验收**：在 `成品画面说明.md` 写清每张照片的人物角色、城市辅助元素与主次关系。不得把女生主体裁掉、遮住、缩成背景小人或替换为纯风景。比例或素材质量不足时继续在 IAB 搜索补齐，不能降低配额或凭空生成女生来补缺。城市插画背景仍按本技能设计要求制作；这里的主次规则针对采集照片与照片展示。

先写第一人称文案，再设计画面。用户没有提供亲历记录时，写“我看着照片想到……”“我想把这一片绿留下”等可从画面引出的感受或愿望，不能编造“我在某日走了某条路线”“我在山顶遇见谁”等亲历事实。多作者照片是独立素材，不能拼成用户的一天。作者事件、路线、天气和日期只用有来源的内容；动态旅游信息需当日核验。若整页生成使原照片被模型重绘，署名应表达为“图像参考：作者”，不声称成品图仍是作者原始实拍；原始照片与来源照常归档。

把所有要出现在图中的中文定为**短且准确**的文字清单：主标题、副标题、2–3段第一人称正文、少量图注与来源标记。不要把详细来源/尺寸说明挤入画面；它们留在内部记录。生成中文可能出错，验收时逐字核对，不能因为画面好看就放过错字。

### 最终成品活页扣：固定九扣，3＋3＋3分组

**生成时固定使用九扣设计**：九个完整扣环沿中央装订轴从上到下排列，三扣一组，共三组。左右半环闭合后算一个扣环；提示词中不要要求六扣、其他扣数或九扣均匀排列。

相邻扣环的中心距固定为下列设计规格，单位 mm，指中心到中心，不是扣环外缘之间的空隙：

```text
扣号：① — ② — ③ —— ④ — ⑤ — ⑥ —— ⑦ — ⑧ — ⑨
间距：  19   19   50.8   19   19   50.8   19   19
```

以第一扣中心为0，九扣中心位置依次为 **0、19、38、88.8、107.8、126.8、177.6、196.6、215.6 mm**。组内间距相等，两处组间大间距相等且约为组内的2.67倍。九扣沿页面高度居中布置，不贴上下边；整体首末扣中心跨度215.6 mm。若单页设计高度为265 mm，上下首末扣中心距页边各24.7 mm。这是当前画面的指定规格，不据此推断其他九孔产品均相同。

`成品画面说明.md` 和每次生成／编辑提示词必须明确写入九扣数量、3＋3＋3分组、完整间距序列及中央装订位置。九扣全部清楚可数，纸卡、照片、文字和装饰不能遮住扣环；环的金属质感、闭合接缝、透视、厚度和接触阴影一致。扣环内径不由孔距推定，用户未指定时保持统一且与本体比例协调。

九扣只约束画面说明和生成提示词；**最终图不检查扣环数量、分组或间距**，即使生成结果与设计规格不同，也不因此重复生成或阻止交付。毫米数值仅指导视觉比例，不能宣称原始输出图达到加工精度。

## 3. 成品画面说明：必须先写完整，再一次生成

在 `成品/<小主题编号与名称>/V<实际版本号>-<内容简述>/` 保存该版完整的`成品画面说明.md`，包含这些具体信息。它既是生成提示词的依据，也是用户能审阅的设计要求：

1. **主题与情绪**：一句话说明要留下的片刻；如武功山草甸的慢行、雾与绿色，而不是通用“唯美旅行”。写清温度、天气、静动关系和色彩气氛。
2. **实物载体**：正上方俯视，皮面或布面旅行活页本，左右两张独立竖页、中央九扣（3＋3＋3，中心距19、19、50.8、19、19、50.8、19、19 mm）、中缝、连续皮纹、纸厚、翘角和接触阴影；环与皮边不占内容页。
3. **完整背景与照片呼应**：按第1节背景要求，写出一整幅连贯场景的远中近景、跨页延续、统一光线与色彩；逐张说明它怎样呼应照片的地点与体验、怎样承托女生主体。明确正文自然净空与照片四周的低干扰区域，照片之间仍能看出连续场景。山野、海岛、街巷或店内环境按真实素材选择，不用零散装饰替代完整背景。
4. **构图与照片**：每张参考照片的内容、角色、方向、外框寸数和大致画面位置；主次不等、边距不机械整齐。若有人像，写衣着、姿势、所处环境与不可遮挡处。照片外框含白边，不把相纸之外的胶带算进照片尺寸；不允许增加虚构照片。
5. **纸张工艺**：毛边须有不对称缺口、细纤维、撕裂层、纸张厚度、卷角与贴近的阴影；不同纸签的撕口、大小、旋角、纸色都不相同。胶带末端也像手撕，有半透明皱折。避免规则矩形、波浪边、棋盘格、统一贴纸模板和满页碎卡片。
6. **字体和文字**：毛笔感大标题，较松的手写正文，少量贴在照片旁的短句。正文尽量直接落在有净空的纸面；纸卡只为局部文字服务。列出每一句准确文字与署名。
7. **氛围和节制**：自然材质、景深、物件与叙事连成一幕；只有与主题有关的压草、地图、脚印等小物。避免无依据票根、邮戳日期、雪山、旗帜、建筑或不相干食物；避免大片纯色照片底板和均匀三格照片墙。
8. **禁覆区与验收目标**：人脸、身体动作、原水印、正文、作者标记、装订中缝保持清楚；完整场景在页边与照片间连续可见，女生照片仍突出；缩小能读清主次，放大能看出纸纤维。

把说明作为**单次完整跨页生成/编辑请求**发给图像生成工具。需要复用旧跨页或照片视觉时用参考图输入；用户指定了现有照片时，尽可能纳入参考图并描述每张照片的人物/景色。每次生成是一张完整成品，不能拆出独立的相纸、纸卡、花草，再用程序机械叠加。若结果不合格，修订完整说明并重新生成**整页**，不对着错误中文字贴覆盖纸条，不在被模型改动过的旧照片上盖另一张照片。

[武功山整页生成示例](references/武功山整页生成示例.md)示范了如何把草甸、人物照片、文字、撕纸工艺和禁项写进同一份说明；它只示范具体程度，不是跨城市通用提示词。

### 每版只交付原始图，版本保留在对应主题内

每个实际制作的页面在每个版本中只保留并交付 **一张通过验收的生成工具原始输出图**，沿用工具实际分辨率与文件格式，文件名采用 `<小主题名>-原始版.<实际扩展名>`。原始输出为 PNG 时交付 PNG；若为其他格式，直接保留实际格式，不为统一后缀转码或仅改扩展名。

不额外生成不同风格、A/B/C图片、高清放大版、打印版、压缩版、预览版、裁切版或格式转换副本，实际制作和修订按 `成品/<小主题>/V1-内容简述、V2-内容简述…/` 分版保存，保留已有版本；不为目标尺寸缩放或改写DPI。前期至少三版详细文字只用于选稿，不要求生成三版图片。用户指定多个页面时每页各一张原始版，不把多页理解成同一页的多个版本。

除九扣差异外，其他质量问题仍按本技能修正并重新生成，每版完成其他验收后选定一张作为该版正式原始图，说明实际采用版本；失败尝试不冒称已通过的新版本。已产生的实际修订版本留在对应主题目录，不能以“只交付一个原始版”为由迁入历史或删除。用户已有旧文件与原始素材不得擅自删除或覆盖；确需替换既有正式文件时按用户明确要求处理。原始版指最终选定输出未经后期加工，不要求交付第一张未通过验收的结果。

## 5. 验收、归档与交付

生成后**必须打开最终图**缩小看整体、放大核字和人物：

- 搜索笔记、候选图与最终选图是否符合女生主体配额；女生照片是否为主视觉，城市照片是否保持辅助地位。
