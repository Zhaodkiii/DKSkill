# 元素分类判定清单

处理每张手账内页时，对照本清单逐项识别。核心判断原则：

> **照片、文字、标签和胶带是可替换排版内容，默认去掉；纸纹、插画、植物与装饰线描保留。胶带不得融入背景或充当位置标记。**

---

## 一、必须保留——纸张底色层

这是背景的基础，任何情况下都保留。

| 元素 | 视觉特征 | 说明 |
|---|---|---|
| 做旧米黄色牛皮纸底色 | 暖调米黄/浅褐色，不是纯白 | 画面的主体底色 |
| 纸张纤维纹理 | 细微的纤维颗粒、不均匀质感 | 扫描级纸张质感 |
| 边缘做旧暗化 | 画面四周轻微的褐色/暖色暗角 | 模拟旧纸自然老化 |
| 纸张斑驳痕迹 | 局部轻微的色差、做旧斑点 | 增加真实感 |
| 撕毛边（页面最外缘） | 纸张边缘不规则的自然撕裂感 | 画面边缘就是毛边，不是整齐切割线 |

**注意：** 底色是"做旧米黄"，不是冷白、灰白。如果模型输出成冷白色底，属于错误，需重新生成。

---

## 二、默认保留——水彩/插画层

手账中大面积的水彩渲染和场景插画，默认保留进背景。它们是页面氛围的主体，不是"可替换的照片"。

| 元素 | 视觉特征 | 典型位置 |
|---|---|---|
| 蓝色水彩晕染 | 淡蓝色水彩在牛皮纸上的晕开效果 | 标题周围、页面边缘 |
| 海景水彩插画 | 海湾、渔船、浮标、海岛的水彩画（非照片，有笔触） | 页面下半部分或整页铺展 |
| 窗景插画 | 木质窗框、飘动窗帘、窗外海景、窗台上的物件 | 页面上半部分 |
| 礁石海浪插画 | 蓝色水彩绘制的礁石、海浪、远山 | 侧边、底部 |
| 星空灯塔夜景 | 深蓝紫色夜空、星星、发光灯塔、海面反光 | 整页背景或局部 |
| 远景渔村/城市建筑群 | 山坡上错落的白色房子（水彩/插画风格） | 左上角、远景 |

**判定关键——插画 vs 照片：**
- **插画/水彩**：有可见笔触、色彩晕染、手绘感 → 属于背景，保留。
- **照片**：写实质感、有白色相框边框、胶带粘贴 → 属于可替换内容，去除。

**例外：** 如果用户明确说"把大幅插画也去掉""我只要纯纸张背景"，则去除插画，输出纯纹理背景（此时画面应均匀铺满牛皮纸纹理）。

---

## 三、必须保留——装饰线描层

蓝色或深色的手绘线条小图案，是手账的装饰骨架，全部保留。

| 元素 | 视觉特征 |
|---|---|
| 飞鸟/海鸟线描 | 简单的"M"形或展翅小鸟线条，常成群 |
| 海浪波纹线描 | 连续的弧形波浪线条 |
| 帆船/小船线描 | 简笔帆船轮廓 |
| 灯塔线描 | 线描灯塔，常带礁石 |
| 指南针/方位标线描 | 圆形罗盘 + N/E/S/W 方位字母、指针 |
| 海岛轮廓线描 | 简笔小岛、山峦轮廓 |
| 植物枝叶线描 | 叶片、枝条的线描 |
| 虚线路线 | 点状/短划虚线路径（表示旅行路线） |
| 小箭头 | 指向性箭头线描 |
| 云纹线描 | 简笔云朵 |
| 小图标（浮标/渔船/潮汐） | 带标注的线描小图 |
| 邮戳印章 | 圆形邮戳、日期戳（印章本身的图形） |
| 邮票齿孔线描 | 锯齿状邮票边框 |
| 水波纹/水纹 | 装饰性水波线条 |

**注意区分：**
- 线描旁边的**汉字标注**（如"浮标""渔船""潮汐"）属于文字 → 去除。
- 线描图形本身 → 保留。
- 指南针上的 **N/E/S/W 字母**是图形的一部分 → 通常随图形保留。

---

## 四、必须保留——实物装饰层

模拟贴在纸上的实物装饰，保留。

| 元素 | 视觉特征 |
|---|---|
| 干花/干花枝条 | 压花质感的干枯花朵、草穗、枝叶（粉色/褐色小花） |
| 贝壳 | 真实质感的贝壳（扇形贝、海螺等） |
| 海玻璃 | 蓝绿色半透明磨砂玻璃碎块 |
| 金色船锚 | 金属质感的小锚装饰 |
| 麻绳结/麻绳网 | 编织的绳结、渔网装饰 |
| 海玻璃/宝石 | 蓝绿色小石块 |

---

## 五、必须全部去除——胶带与粘贴痕迹

所有胶带都属于后续排版时可添加的固定材料，不融入背景，不作为照片位置标记。背景内禁止出现胶带及粘贴痕迹。

- 去除蓝色、灰色、牛皮纸色、粉色、绿色等全部胶带，包括格纹、半透明条、边缘残片、褶皱、翘角、残胶、投影和压痕。
- 胶带贴在花叶、插画或线描上也要去除；自然补全被遮挡的花叶、线条和纸张纹理，不误删下方装饰。
- 去除后不得留矩形色块、斜条、浅色胶带轮廓或粘贴痕迹。
- 生成提示逐处列出胶带位置，验收逐处对照原图检查；发现残留须重新生成。

---

## 六、必须去除——照片层

所有相框内的照片图像，全部去除。无论内容是什么。

识别特征：
- 有**白色或米色相框边框**（照片白边）。
- 照片边缘常做**撕毛边**处理。
- 角落有**胶带粘贴**。
- 内容是**写实图像**（风景、人物、日落、船只、建筑等）。
- 可能有**胶片边框**（黑色电影胶条样式）。

常见照片类型（均去除）：
- 风景照（海湾、海岛、山线、灯塔、礁石）
- 人物照（剪影、背影、侧脸、合影）
- 日落/日出照
- 室内照（卧室、阳台、早餐桌）
- 胶片风格照片

**去除后的处理：** 照片所在位置应自然露出下面的牛皮纸底色和水彩晕染，相框边框也一并消失，不能留下白色矩形框。

---

## 七、必须去除——文字层

页面上所有可读文字，全部去除。

| 类型 | 示例 |
|---|---|
| 大标题（书法体） | "海面上，也有田野""灯塔替我们守着夜晚" |
| 地点标签 | "舟山·枸杞岛""舟山·花鸟岛" |
| 正文手写段落 | 整段抒情文字 |
| 照片标签文字 | "风车山线""最后一抹金色""早餐，慢慢吃" |
| 日期/岛屿填空 | "岛屿：____""日期：____" |
| 页码 | "02—03""04—05" |
| 图标旁汉字标注 | "浮标""渔船""潮汐" |
| 结尾署名 | "—海风会替我们记得" |
| 填空下划线 | 标签上的横线 |

**例外：** 指南针上的 N/E/S/W 是图形方位标，随线描保留，不作为"文字"去除。

---

## 八、默认去除——标签框与便签

| 元素 | 默认处理 | 说明 |
|---|---|---|
| 空标签框（带金属孔） | 去除 | 照片下方的牛皮纸标签，带圆形金属孔，用于写字——去掉照片和文字后，标签框本身也去除 |
| 撕边便签形状 | 默认去除 | 如"那天的天气"便签、底部撕边纸条 |
| 便签上的线描（太阳/云朵） | 跟随用户要求 | 如果用户保留便签则保留线描；如果用户说"去掉便签和太阳云朵线描"则全部去除 |

**注意：** 这类元素存在歧义，处理时优先遵循用户的明确要求：
- 用户说"保留撕边纸条形状但不要写字" → 保留空形状。
- 用户说"不要保留撕边便签和太阳云朵线描" → 完全去除，底部恢复平整牛皮纸。

## 九、快速判定流程图

```
页面上的一个元素
│
├─ 是纸张底色/纹理/做旧质感？ ──→ 保留
│
├─ 是水彩/手绘插画（有笔触）？ ──→ 默认保留
│                                   └─ 用户明确要纯背景？ → 去除
│
├─ 是线描小图案（飞鸟/波浪/船/灯塔/指南针…）？ ──→ 保留
│
├─ 是实物装饰（干花/贝壳/海玻璃/船锚/麻绳）？ ──→ 保留
│
├─ 是胶带或粘贴痕迹？ ──→ 必须全部去除，禁止融入背景
│
├─ 是写实照片（有相框/胶带）？ ──→ 去除
│
├─ 是可读文字/标题/页码/填空线？ ──→ 去除
│
└─ 是空标签框/便签？ ──→ 默认去除，按用户明确要求调整
```

## 十、常见错误（需避免）

0. **胶带融入背景**：旧规则曾把胶带误当成必须保留的装饰骨架。必须去除全部胶带及痕迹；花叶上的胶带也要清除并补全下方装饰，验收必须检查每个原胶带位置。
1. **输出白边**：模型在纸张外加白色背景 → prompt 必须强调"四边到边、纯平面扫描件"，生成后检查四角。
2. **留下白色矩形框**：去掉照片但残留相框白边 → 明确要求"相框边框一并消失，露出底色"。
3. **误删插画**：把水彩海景当成照片去掉 → 区分"手绘笔触"vs"写实照片"。
4. **误删装饰线描**：把飞鸟、波浪等线描当成多余内容 → 线描是背景骨架，保留。
5. **格式错误**：sips 输出 JPEG 但扩展名写 .png → 用 `file` 命令验证真实格式，必要时加 `-s format png`。
6. **DPI 未生效**：sips 对 PNG 写 DPI 可能失败 → 用脚本写 pHYs chunk。
7. **尺寸与原图不一致**：输出前未核对原图规格 → 必须读取原图像素/DPI，输出完全一致。
8. **基于上一张背景叠加修改**：导致累积失真 → 迭代时始终基于原始内页图重新生成。
