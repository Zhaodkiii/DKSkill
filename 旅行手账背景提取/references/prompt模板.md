# image_edit Prompt 模板

提炼背景时，按以下模板组织 prompt。方括号 `[]` 处替换为该页面的具体内容。

---

## 标准模板

```
将这张手账[左/右]页进行编辑：背景明确不要胶带，禁止任何胶带及粘贴痕迹融入背景。

完全去除所有照片内容：
- [照片1位置]的[照片1内容]照片
- [照片2位置]的[照片2内容]照片
- [照片3位置]的[照片3内容]照片
（相框边框一并去除，不要留下白色矩形框）

完全去除所有文字内容：
- 大标题"[标题原文]"
- 标签文字"[标签原文]"
- [正文/页码/填空等逐条列出原文]

完全去除所有胶带与粘贴痕迹：
- [逐处列出位置、颜色和形状，包括花叶上的胶带与边缘残片]
- 连同格纹、半透明色块、残胶、投影、压痕和胶带轮廓一起去除，绝不融入背景，不保留为照片位置标记。
- 重建被遮挡的纸纹、花叶和线描，不误删下方装饰。

照片、文字、标签与胶带去除后，原来位置自然露出下面的做旧米黄色牛皮纸底色。

完整保留以下视觉元素不动：
- 做旧米黄色牛皮纸底色、纸张纤维纹理和边缘做旧暗化
- [蓝色水彩晕染的位置]
- [大幅水彩插画：描述内容，如"蓝色海湾、红色渔船、浮标、远处海岛渔村"]
- [线描元素逐条列出：如"右上角飞鸟线描""右下角海浪波纹""左侧指南针方位标"]
- [实物装饰：如"干花枝条""贝壳""海玻璃""金色船锚""麻绳结"]
- [邮戳/邮票齿孔等]

画面四边就是纸张边缘，绝对不存在任何白色背景、白色边框、外围留白。不要把纸放在桌面或白色背景上，不展示书本、不展示环境——这是一张纯平面的、占满整个画布的手账内页扫描件。

输出一张手账页背景底图，有[保留的装饰元素概括]，但没有照片、文字、标签、胶带、残胶及粘贴痕迹，无任何白边。
```

## 纯纹理背景模板（用户只要纸张，不要插画）

```
将这张手账[左/右]页中的所有内容元素完全去除：
- 所有照片：[逐条列出]
- 所有文字：[逐条列出]
- 所有插画：[逐条列出，如"大幅海景水彩""窗景插画"]
- 所有标签框、便签、胶带及粘贴痕迹
- 所有装饰线描、干花、贝壳等（如用户要求纯背景）

最终输出一张纯净、均匀、无缝的做旧米黄色牛皮纸纹理，保留纸张自然纤维质感和轻微做旧斑驳痕迹。画面中没有任何文字、图案、照片、装饰，就是一张干净的牛皮纸扫描纹理，四边到边铺满，无白边。
```

## 迭代模板（用户要求增删特定元素）

迭代时基于**原始内页图 URL**，只改动用户点名的部分：

**用户说"XX 也要保留"：**
```
将这张手账[左/右]页进行编辑：背景明确不要胶带，禁止任何胶带及粘贴痕迹融入背景。去除所有照片、文字、标签和胶带及痕迹[同标准清单]。
特别注意：[用户点名的元素，如"左上角山坡上的白色渔村建筑群"]必须完整保留，[描述其位置范围]。
其余保留/去除项同标准要求。输出无照片、无文字、无白边的背景底图。
```

**用户说"不要保留 XX"：**
```
将这张手账[左/右]页进行编辑：背景明确不要胶带，禁止任何胶带及粘贴痕迹融入背景。去除所有照片、文字、标签和胶带及痕迹[同标准清单]。
同时完全去除[用户点名元素，如"底部撕边便签形状和太阳云朵线描"]——该区域恢复为平整的做旧米黄色牛皮纸。
其余保留项不变。输出无照片、无文字、无白边的背景底图。
```

## 填写示例（以枸杞岛"海面上也有田野"左页为例）

```
将这张手账左页进行编辑：

完全去除所有文字内容：左上角"舟山·枸杞岛"标签文字、大标题"海面上，也有田野"全部文字、
三段正文（"陆地上的田野……""一排排浮标……""把这一片海收进手账……"）、
右下角"浮标""渔船""潮汐"标注文字。

完整保留：右上角飞鸟线描；下半部分大幅水彩海景插画（左上角山坡白色渔村、红色灯塔、
蓝色海湾、红色渔船、整齐浮标养殖区、远处绿色海岛、蓝天白云）；
右下角三个蓝色线描小图标（浮标、渔船、潮汐波纹图形）；做旧牛皮纸底色。

画面四边就是纸张边缘，无白色背景、无白边，纯平面扫描件。
输出有完整海景插画和线描、但没有任何文字的背景底图。
```
