# 小鲸应用封面

## 核心目标

根据用户提供的 App 截图，先自动归纳一个统一主题，再生成 1242×2688 竖版 App Store 产品介绍封面图。用“小鲸”动画角色把产品核心功能讲清楚，同时给真实 App 截图预留正式、可后期替换的占位区。

画面不是普通插画，也不是完整 UI 截图。它应该像 App Store 宣传图：一部分是可爱的功能动画解释，一部分是严谨的截图承载区域，两者要互相呼应。

## 默认生成规则

- 一次请求默认只生成一个主题，不要把每张截图拆成独立主题。
- 用户提供多张截图时，先阅读截图内容，提炼共同的产品主题和 2-4 个关键功能点。
- 如果截图都属于同一功能集合，要合并成一个主题封面，并为关键功能分别预留截图区域。
- 每一张封面都必须预留截图区域，最少 1 个、最多 3 个；只有当用户主动明确说“不需要截图区域 / 不留截图区域 / 纯插画”时，才可以不留。
- 如果关键功能超过 3 个，合并相近功能，只保留最多 3 个截图预留区。
- 默认生成 4 个同主题不同构图 / 不同风格版本，方便用户选择。
- 不需要用户每次额外说明“合并主题、留截图区域、生成四个版本”；除非用户明确指定数量或单张风格，否则按此默认执行。
- 每个版本都必须包含同一个主题和同一组关键功能，不要把功能拆散到不同版本里。
- 每个版本的截图占位区位置、比例、构图关系要有差异，避免四张只换颜色或小装饰。

## 必须包含

- 1242×2688 竖版 App Store 封面图。
- 纯白或极浅灰背景，大量留白。
- 小鲸 IP：天蓝色圆润蓝鲸动画人物，白色竖纹肚皮，粉色脸颊，短手短脚，尾鳍，头顶水滴喷泉。
- 正式截图占位区：空白内容、圆角矩形、细虚线描边、像真实截图容器。每张封面最少 1 个、最多 3 个截图占位区；截图占位区数量根据主题关键功能决定。如果截图体现 3 个关键功能，就预留 3 个截图区域；如果超过 3 个关键功能，合并为 3 个以内。
- 截图占位区和动画主题融合：小鲸的动作、道具、路径、箭头或状态变化要指向这个截图区域。
- 少量中文卖点文字，短、准、像 App Store 截图标题，不要说明书式长句。

## 截图占位区规则

截图占位区是后期放 App 截图的位置，生成时必须保持空白。

- 每张封面默认必须有截图占位区，最少 1 个、最多 3 个。
- 只有用户主动明确要求不需要截图区域时，才可以生成没有截图占位区的纯插画封面。
- 不要因为主题偏抽象、素材不足或用户没有明确说“留截图区域”就省略截图占位区。
- 可以是整张手机截图比例的大区域。
- 也可以是某个功能局部的突出区域，例如药品卡片、用药记录、服药计划卡片、拍照识别区域。
- 位置按主题变化，不要四张都放同一个位置。
- 占位区要像正式设计元素，不像临时草稿。
- 只用空白虚线框表达占位，不要生成 UI 内容、状态栏、按钮、表格、药品文字或手机截图。
- 不要写任何占位提示语、替换提示语或说明性引导文字。
- 可以用轻微阴影、浅色底、圆角和虚线让占位区成立，但内部必须干净空白。

## 主题与截图区域建议

### 多截图合并主题

当用户给出多张截图时，先找出它们共同服务的产品任务，然后合成一个主题封面。

- 例如截图包含“服药计划、按时用药、家庭药箱”，统一主题应归纳为“用药管理”或“家庭用药管理”。
- 同一张封面内必须同时包含“服药计划、按时用药、家庭药箱”三个功能语义。
- 预留 3 个正式截图区域，分别承载这三个功能；三个区域可以是三联屏、环形路线、抽屉分区、时间轴卡片等不同构图。
- 默认生成 4 个版本，四个版本都保留同一主题和这三个功能，只改变构图、动作隐喻、占位区布局和文案表达。
- 推荐短文案：用药计划 清楚提醒 / 三件事 一起管 / 家庭用药 有条理 / 每天用药 不漏掉。

### 家庭药箱

核心意思：家里所有药品被整理成清晰药箱。

- 截图区可放右侧或中部，适合整张药箱列表截图。
- 小鲸在旁边整理药盒、贴分类标签、把药品放进白色收纳格。
- 动画元素围绕截图区形成“分类、归档、查看更多”的感觉。

### 拍照添加药品

核心意思：拍一下药盒，就能快速添加药品。

- 截图区可放画面中央偏下，模拟相机取景框，但内部必须空白。
- 小鲸举相机、扫描光线、药盒轮廓和识别小星点围绕截图框。
- 截图框可以更像功能局部，而不是整张手机屏。

### 今日用药记录

核心意思：每天用药是否完成，一眼看清。

- 截图区可放左侧或下方，适合放用药记录列表截图。
- 小鲸拿勾选笔、沿时间线点亮圆点，表现“已记录、已完成、按需用药”。
- 动画要突出记录和完成感，不要画复杂日历 UI。

### 服药计划

核心意思：长期处方和服药计划集中管理。

- 截图区可放下半部分横向大框，适合放计划卡片或处方局部。
- 小鲸连接药丸、铃铛、医院卡片和进度状态。
- 动画要体现“计划、提醒、进行中、已结束”的秩序感。

## 文案风格

文字要短，适合封面大标题或功能卖点：

- 家庭药箱，一眼找药
- 拍照添加，快速建档
- 今日用药，轻松打勾
- 服药计划，清楚提醒

避免大段说明，避免医学承诺，避免夸张疗效。

## 禁止

- 禁止生成真实 App 截图或伪造截图内容。
- 禁止在截图框里放 UI、文字、药品列表、状态栏或按钮。
- 禁止写任何占位提示语、替换提示语或说明性引导文字。
- 禁止把截图框做得太随意、太像草稿或开发线框图。
- 禁止只画小鲸，不留正式截图区域。
- 禁止复杂 PPT、商业海报、儿童贴纸、重渐变、深色背景。
- 禁止让小鲸变成普通蓝色动物；必须保留喷泉识别点。

## 生成后检查

交付前逐张检查：

- 尺寸是否为 1242×2688。
- 是否有明确、正式、空白的虚线截图占位区。
- 截图占位区数量是否为 1-3 个；除非用户明确要求不需要，否则不能为 0 个或超过 3 个。
- 截图框内部是否完全空白。
- 是否没有任何占位提示语或说明性引导文字。
- 截图区位置是否贴合主题，并且四张之间有变化。
- 小鲸是否参与核心动作，而不是站在旁边装饰。
- 小鲸是否保留喷泉、肚纹、短手短脚和尾鳍。
- 中文是否短、准、无明显错字。
