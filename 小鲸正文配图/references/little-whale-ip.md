# 小鲸 IP

## 角色定义

小鲸是中文正文配图的固定视觉 IP，来源于参考图里的 Little Whale 角色设定。

默认每张图都要出现小鲸。小鲸不是普通鲸鱼图标，不是贴纸素材，不是只负责卖萌的装饰，而是带手脚、能行动、能表达文章结构的动画人物。

每个 IP 都必须有一个“一词识别点”。小鲸的识别词是：**喷泉**。

生成时必须保留头顶水滴喷泉，或把喷泉变成参与动作的视觉机关。没有喷泉时，小鲸容易漂移成普通蓝色圆形角色。

## 外形

- 圆润 Q 弹的天蓝色小蓝鲸，整体像站起来的鲸鱼宝宝。
- 头身一体，身体偏圆，侧面保留鲸鱼轮廓和小尾鳍。
- 白色肚皮占身体前侧 30%-45%，有浅蓝竖向肚纹。
- 头顶有 3-5 个水滴组成的喷泉，这是最高优先级识别点。
- 粉色圆形脸颊，表情明亮但不要过度夸张。
- 短圆手臂，拳头或 mitten-like 小手，可以挥手、搬、推、抱、指向。
- 短粗小腿和圆脚，必须让角色看起来像“人物”，不是趴着的鲸鱼。
- 小尾鳍在身体后侧或右侧，尾鳍不能缺失。
- 眼睛可用月牙笑眼、黑圆眼、困眼、泪眼、眨眼，但要保持干净友好。
- 皮肤有柔和蓝色渐变和小面积高光，边缘干净，不要厚重黑描边。

## 性格

- 热情、积极、亲和，像正在帮用户解决问题的小伙伴。
- 可以开心、惊讶、疲惫、难过、生气、眨眼、紧张，但情绪要服务文章含义。
- 行动感强，愿意跑、跳、推、搬、举、拉、记录、引导。
- 角色更像动画主角，不是静态 logo。
- 保持聪明和可靠，不要变成低幼儿童角色。

## 常见职责

让小鲸承担核心动作：

- 用喷泉喷出提示、反馈、灵感或系统状态。
- 用小手搬运素材、推流程、抱住结果、举警告牌。
- 用短腿跑过路径、跳过断点、踩住关键节点。
- 用尾鳍指向方向、平衡身体、推动水流或路径。
- 把抽象概念变成水泡、浪花、漂流瓶、救生圈、小船、管道、贝壳、浮标。
- 在流程中承担操作员角色：分拣、连接、修补、托举、守门、记录、检查。
- 通过表情库表达状态：surprised / tired / sad / angry / winking / nervous。

## 禁止

- 不要出现“小黑”、黑色怪物、黑豆、影子人、黑盒角色。
- 不要把小鲸画成普通真实鲸鱼、海豚、鲨鱼、鱼、海豹或蓝色圆球。
- 不要缺少喷泉、白肚纹、尾鳍、短手短脚。
- 不要画成趴着游泳的动物，除非任务明确要求侧面或水下场景；默认要能站立行动。
- 不要复杂服装、复杂配饰、超写实材质、毛发、鳞片或真实海洋动物纹理。
- 不要把角色画得过度幼稚、廉价贴纸化、表情包化。
- 不要让小鲸只是站在角落里看。
- 不要让小鲸抢走结构表达；可爱度要服务信息表达。
- 不要暗色背景、复杂海底背景、满屏珊瑚、强烈渐变、厚重阴影。
- 不要在同一张图里塞入完整设定板、色卡或多角色表情矩阵，除非用户明确要求 model sheet。

## 判断标准

如果去掉小鲸，图的核心隐喻还能完全成立，说明小鲸太装饰了；要重写提示词，让小鲸成为动作主体。

如果遮住喷泉后仍然无法一眼认出这是小鲸，说明角色识别点太弱；要重写提示词，强化“喷泉 + 白肚纹 + 短手短脚 + 尾鳍”。
